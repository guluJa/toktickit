# Lab 4 Issue #69: isolated migration and recovery evidence

Date: 2026-10-02
Source database: local `toktickit_e2e` only. The Development database was not migrated, reset, or restored.
Credentials, database URL, password hashes, and row snapshots are intentionally omitted.

## Command run from the repository root

```powershell
$dbLine = Get-Content -LiteralPath 'server/.env' | Where-Object { $_ -match '^DATABASE_URL=' } | Select-Object -First 1
$raw = ($dbLine -replace '^DATABASE_URL=', '').Trim('"')
if (([uri]$raw).AbsolutePath -ne '/toktickit') { throw 'Unexpected source database name.' }
$env:DATABASE_URL = $raw.Replace('/toktickit?', '/toktickit_e2e?')
& '.\artifacts\lab-04\verify-recovery.ps1'
```

The script verifies that `DATABASE_URL` names local `toktickit_e2e`, writes a custom-format `pg_dump` to a temporary file, creates a uniquely named scratch database, restores it with `pg_restore`, and compares row counts and complete row snapshots for RequesterUser, Ticket, Attachment, Comment, InternalNote, and ActionTaken. It then drops only the scratch database created by this run and removes the temporary dump.

This tests migration preservation; the backup/restore run above tests recovery of the already migrated test database.
